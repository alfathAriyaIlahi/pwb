Informasi Aplikasi

Aplikasi ini digunakan untuk mengelola data mahasiswa, termasuk menambahkan, mengedit, dan menghapus data mahasiswa.

Tentang Aplikasi

Aplikasi ini digunakan sebagai media latihan pembuatan halaman HTML5.
